# Personal Vault: The Boss Omni-Protocol

## 1. PARA Framework
- `01 Projects`: Time-bound efforts (e.g., [[AI Email Auditor]]).
- `02 Areas`: Ongoing responsibilities (e.g., Faith, Health, Family).
- `03 Resources`: Knowledge library (The core research).
- `04 Archives`: Completed or legacy items.
- `90 Templates`: Boilerplates for new notes.

## 2. Linking & Taxonomy
- **People**: Link via `[[Full Name]]`. Keep source files in `03 Resources/People Contacts`.
- **Dates**: Use `[[YYYY-MM-DD]]` to link to daily notes.
- **Tags**: 
  - Status: `#status/active`, `#status/pending`
  - Type: `#type/video`, `#type/meeting`, `#type/research`
  - Domain: `#domain/theology`, `#domain/tech`

## 3. Workflow Protocol
1. Create new note using the appropriate template from `90 Templates`.
2. Populate frontmatter metadata (Date, Tags, URL).
3. Cross-link via `[[Wiki-links]]` to existing projects or people.
4. Git push changes to origin/main.
