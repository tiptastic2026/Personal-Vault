Problems & Troubleshooting
Problem — Persistent Memory Became Too Large
Symptom:
Project-specific information and detailed operating rules risked being stored as permanent memory.
Cause:
No clear separation initially existed between the Master AI System, persistent memory and individual projects.
Solution:
Established three layers:
1. Master AI Operating System — system rules.
2. Persistent memory — stable user preferences and supporting context.
3. Project files/repositories — project implementation and history.
Prevention / Lesson:
Do not duplicate the Master AI System in persistent memory. Do not store temporary project details as permanent user preferences.

Problem — Specialist Rules Becoming Scattered
Symptom:
Specialist behaviour was distributed between different instructions and memory.
Cause:
The system had developed incrementally.
Solution:
Consolidated specialist modes and their operating rules into the Master AI Operating System.
Prevention / Lesson:
The Master AI Operating System should remain the single authoritative location for detailed specialist behaviour.

Notes
The AI project is the system that governs how AI assistance is configured and used.
It is separate from individual projects carried out using the system.
The YouTube scraper is therefore not part of this project merely because the AI system contains a YOUTUBE mode.
The YOUTUBE mode defines how the AI should analyse YouTube material. The scraper remains its own technical project.

Final Result
The AI project has been established as a version-controlled system with a central Master AI Operating System, supporting persistent memory and clearly separated individual projects.

Lessons Learned
- The AI system should have a clear hierarchy: Master AI Operating System → Persistent Memory → Individual Projects
- Detailed operating rules belong in the Master AI Operating System.
- Stable personal preferences belong in persistent memory.
- Implementation details and historical records belong in their respective project files and repositories.
- Individual projects should not be absorbed into the AI system merely because the AI system provides a mode for working with them.
